# Bundled Tesseract OCR

The Windows runtime is fetched from the UB Mannheim Tesseract distribution by
`scripts/fetch-tesseract.ps1`. The pinned installer and its SHA-256 are recorded
in that script. Tesseract and its language data are licensed under Apache-2.0;
the fetched runtime contains the upstream license files.

Source: https://github.com/tesseract-ocr/tesseract
Windows distribution: https://github.com/UB-Mannheim/tesseract
