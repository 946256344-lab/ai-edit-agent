# Voycut 首发检查清单（目标 2026-10-01，海外优先）

本文件是首发前后的检查清单，逐项勾选。事实依据写在每项「现状」里，基于 2026-09-26 的桌面仓库与本机 `../website` 仓库；状态变化时直接改本文件，并在 `TASKS.md` 更新总条目。

2026-09-26 已把标为 `缺失` 的项逐条回到两个仓库的代码和配置里核实过。只能在控制台确认的项（Firebase Key 限制、发件域、Firestore 规则是否已部署、Vercel 套餐与执行时长、上游服务条款）标为 `待确认`。

状态标记：`缺失` 未做；`部分` 做了但未验收或有缺口；`待确认` 需要查控制台或实测才知道；`已具备` 有实现且有验证记录。

优先级：**P0** 不完成不能发；**P1** 发布前应完成，来不及要在已知限制里写明；**P2** 发布后第一周。

## 0. 决策

### 已定

- [x] **D2 目标市场：海外优先**（2026-09-26）。
  - 用户默认用英文界面，交付目标是 CapCut 国际版、DaVinci Resolve 和 Premiere，剪映降为次要。
  - 账号走 Firebase，网关部署在 Vercel，海外直连可用，不需要为代理或大陆可达性另做改造。
  - 合规按 GDPR / UK GDPR / CCPA 准备；大陆相关事项放进 §6 暂缓。

### 待定

- [ ] **D1 发布形态**：公开下载，还是邀请制 Beta（建议 20–50 人）。建议邀请制：没有自动更新和崩溃上报，出问题的影响面要可控。
- [ ] **D3 试用与付费**：
  - 现状：`entitlements/{uid}` 由网站在邮箱验证后创建，`status: trial`，网关按 7 天判定有效（`../website/lib/model-gateway.js`）。试用期内**不限次数、不限费用**。`paid` 状态客户端不能写，只能在控制台手工改。没有支付流程。
  - 需要定：试用期内的每日额度；试用结束后怎么办（项目仍可打开，AI 功能停用，这一点要提前告知用户）；首发是否收费。
  - 海外收费建议用代收型支付（Merchant of Record，如 Paddle、Lemon Squeezy），由平台代缴欧盟增值税和美国销售税。直接接 Stripe 的话，税务要自己处理。
- [ ] **D4 上游模型与单次成本**：
  - 现状：网关固定使用 `FELLOWCUT_MODEL_NAME`。网关模式下 `coarseVisualModel` 为空，素材批量视觉分析也走主模型。导入素材后会自动发起分析，用户还没剪片就已经在消耗额度。
  - 需要实测：导入 100 条素材的分析费用；一次 30 秒成片（含替换一镜）的费用；试用用户用满 7 天的最坏情况费用。模型必须同时支持视觉、工具调用和 JSON 输出。
- [ ] **D5 配音**：网关不代理配音。公开用户没有 ElevenLabs / Fish Audio 密钥，默认就没有配音。三选一：隐藏配音开关；标注为「高级：自带密钥」；在网关里代理 ElevenLabs（海外更常用，会增加成本）。背景音乐（Jamendo）同样需要决定，Jamendo 曲目用于商业用途需要单独授权。
- [ ] **D6 交付物口径**：没有最终 MP4 导出。应用只生成 540×960 低清预览，以及 CapCut / 剪映 / FCPXML / OTIO 工程（`src-tauri/src/preview.rs` 顶部注明不负责最终导出）。官网和首次引导必须写清楚「成片要在 CapCut 或 Resolve 里导出」。海外用户对「AI 剪辑」的预期通常是直接拿到 MP4，这一点要写在最显眼的位置。

## 6. 暂缓：中国大陆市场

决定进入大陆市场时再启用这一节。

- 账号（Google API）和网关（Vercel）在大陆不可达；桌面端的模型与账号请求不读取代理环境变量，只有配音请求读取（`src-tauri/src/outbound_http.rs`）。要么换成大陆可达的账号与网关，要么明确要求用户开启 TUN 模式代理。
- 默认编辑器改回剪映；验证剪映当前版本的草稿兼容性（已验证过剪映专业版 8.0 的纯视频草稿）。
- 生成式 AI 服务备案；《人工智能生成合成内容标识办法》对合成配音的标识要求；官网服务器放在大陆时需要 ICP 备案（要数周）。
- 验证邮件在 QQ / 163 邮箱的送达情况；安装包走国内 CDN；模型下载走 hf-mirror（已实现）。
- 国内支付（微信 / 支付宝）需要营业执照主体。
