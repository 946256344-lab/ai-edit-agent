# 素材根目录重新定位

2026-08-11

## 问题

导入后移动文件夹、断开磁盘或更换盘符会令项目保留失效的源引用。重新导入会创建重复素材，不能安全地恢复既有 storyboard、时间线和 Jianying draft 的素材关联。

## 决策

增加用户明确触发的两阶段流程：

1. `preview_asset_relink` 扫描新根目录，只将唯一的旧相对路径且媒体类型相同的候选报告给 UI；不修改数据。
2. 用户确认后，`confirm_asset_relink` 重新计算相同匹配，更新选中素材源引用与文件夹根，清除旧元数据，取消旧 active 分析任务并创建新的 queued 分析任务。
3. 只启动首批 4 条分析，剩余任务使用现有队列渐进处理。不能唯一确认的素材保持原引用。

该机制不按文件名推断媒体内容，也不会自动把不确定候选接入既有镜头。

## 验证

- `cargo test`：46 单元 + 2 集成测试通过。
- `npm run lint`、`npm run build` 通过。
- 待新安装版手工选择真实素材根目录验证。
