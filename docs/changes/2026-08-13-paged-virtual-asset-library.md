# 分页与窗口化素材库

## 变更

- 新增 `list_asset_page` 桌面命令，单页限制为 1–200 条。
- 搜索、媒体类型、技术状态、视觉状态、storyboard 可用性和文件夹条件下推 SQLite。
- 返回匹配总数、项目级技术状态计数与安全文件夹 facet，列表统计不再由当前页推断。
- 前端默认读取 100 条，接近列表底部时续页；只挂载可视行和 5 行 overscan。
- 轮询只刷新首批摘要，并保留已经加载的后续页；筛选变化时重建当前分页结果。

## 边界

- 既有内部 Agent `list_assets` 工具保持不变。
- 分页响应不包含绝对源路径，查询不执行文件系统探测。
- 此阶段不增加删除、移动或覆盖副作用，也不启动或重启桌面程序。

## 验证

- Rust 定向测试覆盖搜索、文件夹、媒体类型、技术状态和 storyboard 可用性组合条件。
- `npm run lint`
- `npm run build`
- `cargo test --lib`
- `npm run harness:check`
