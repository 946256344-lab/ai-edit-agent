# Preview 时间线作用域修复

日期：2026-08-10

显式“生成预览”原先会在前端未携带 storyboard 版本时先构造空时间线候选集，即使请求已携带同一剪辑任务中的有效时间线也会被错误拒绝，FFmpeg 因而不会启动。

现在仅在没有 storyboard 上下文时按项目和剪辑任务查询时间线候选；指定的时间线必须仍属于该作用域。此情形不再由后端写死为立即渲染，而是把“已验证时间线存在、storyboard 上下文缺失”的事实交给模型，由模型在受控技能中决定直接渲染、先观察时间线或澄清。preview 与 Jianying draft 因此可复用已验证的时间线，同时不允许跨项目或跨剪辑任务访问。
