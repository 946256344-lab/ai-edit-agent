# 剪辑流畅度与成片决策优化

## 范围

- 分支：`codex/smooth-editing-pipeline`；基于 `origin/master` 建立并保留本地 `5230902` 的完整文案与配音修复。
- 预览镜头、底片、文字/叠加视频跨时间线版本复用；源版本、源窗口、裁剪变化失效。只有音轨改变时复用合成视频，字幕与叠加画面在一次编码中合成。桌面预览任务移到工作线程。
- 素材与健康摘要空闲停止轮询；活动期间完成一次请求后再安排下一次，避免请求叠加。导入、重链路、扫描、Agent 终态主动刷新；技术/视觉队列交接通过项目事件唤醒，项目级视觉待处理计数避免只观察当前页。健康摘要只在计数或任务状态变化时 bump 素材页，避免扫描中每 2s 重复 IPC。
- 候选池不再提前参与实际镜头的复用惩罚；长素材按可用窗口容量评分。批量向量编码与 TTS 并行，实际选片仍在两者完成后执行。
- 真实配音时间戳可对应完整 beat 原文时，按逐 beat 时段安排镜头，在源窗口容量内优先选停顿切点；容量不足交回现有精修。标准化后验证逐 beat 时长仍成立。
- 在现有视觉请求中加入整条镜头衔接判断与源画面主体中心 `cropFocus`。焦点进入时间线、FFmpeg 竖屏预览和 Jianying 草稿；源替换清除旧焦点，旧数据保持默认行为。
