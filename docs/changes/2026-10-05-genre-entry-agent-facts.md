# 体裁入口与 Agent 事实回复（任务 7）

本任务只改输入入口、发送快照和 Agent 执行/回复边界；不接任务 3–6 的策划、淘汰、选镜或时钟。没有启动桌面 GUI、开发服务器、编辑真实应用数据库、推送或合并。

## 入口与接口

- 输入框在画幅旁提供「自动 / 叙事 / 宣传 / 花絮」，默认自动。`MediaOptions.genre` 用 `auto/narrative/promotion/bts`，随现有 `submit_conversation_turn` 的 `input_json.mediaOptions` 保存，恢复当前会话最近已发送选择；未发送选择只留在 controller 内存。
- `media_options::GenreSelection` 与任务 2 的已判定 `models::Genre` 分开。旧快照缺字段读为自动；`guard_model_options` 总是保留 composer 体裁，模型不能改手选或提前代替生成链判断自动。`generate_storyboard.mediaOptions` schema 包含该字段，原有生成函数直接收到带体裁的快照。
- 故事版的事实 `genre` 从 `storyboard_evidence_metadata` 读取；当前生成链无附加元数据时返回 null，不根据请求填假结果，也不制造 pipeline/recipe/evidence 值。任务 6 应在新生成事务写完整元数据，本任务自动读取它作为结果说明。前端读取类型预留可选 nullable genre。

## Agent 边界

- 每轮额外一次只读模型请求，结合当前会话快照和最近文本识别完成条件（普通回答、新生成、局部画面改动、其他编辑），不选工具或安排素材。普通回答禁写；生成/局部编辑没有对应写回执时最多续步两次，之后诚实失败。手选体裁或媒体开关本身不会触发生成。
- 辅助素材/音乐查询失败不阻止上述写入续步，避免还没尝试生成就结束；真正的写工具失败沿用恢复或诚实结束。没有放宽领域校验或允许自动切换 Provider。
- 写工具返回值必须引用本会话的实际持久化行；独立预览/编辑器工具还核对磁盘产物。生成/局部编辑无可播放画面不能 completed，写入存在但预览/交付/质量检查未完成时为部分完成。最终产物说明由版本、镜头数、实际音文轨和回执生成，模型总结不能覆盖它。
- 普通问答另做一次用户文案请求，只携带用户问题、允许展示的计数/版本/状态及去除指令/ID/路径后的只读观察，不传模型草稿、工具目录、完整系统快照或原生调用协议，没有工具可执行。要求按界面语言回答、删除内部流程指令/候选预算/算法参数、避免主动邀约和默认值确认。该请求失败就如实失败，不将草稿当作已完成答案。
- 普通回复最后复核工具名、内部媒体字段、系统指令标记、路径、UUID 与推理标签；危险内容隐藏并将回合标 failed，不能隐藏后仍 completed。明确关闭的推理标签只保留其后的答案，未关闭的块拒绝展示。盘符匹配保留字符边界，HTTPS 链接不能误当内部路径。工具失败按界面语言给出安全阶段说明，不透传底层错误。
- 完成条件解析读取完整且一致的函数调用。真实 Provider 曾把 requirement/preserveNarration 拆为部分调用，随后给出重复的完整调用；不再仅取第一条，不完整或互相矛盾仍报错，不猜默认授权。
- 已恢复的失败从回执中移除；预览成功只清掉预览缺口，不能清掉质量或交付缺口。中断时已保存的分镜/时间线仍如实说明，不能一面返回产物一面说没有写入。素材分析排队是部分完成；下载音乐另核对项目资产行和真实文件，只说明入库，不冒充时间线 BGM。
- 局部编辑比较实际 source identity/range；没有变化如实失败，不能以重新分配版本号宣称成功。领域局部编辑仍属任务 5，当前后置检查不重写它的事务。
- Agent 目录、白名单、TypeScript 镜像及版本化 fixture 一起移除 `transcribe_asset`；旧调用的 skills 分派也如实报未实现，不返回字幕占位。
- `search_assets` 对 Chat 适配器遗漏的可选过滤补默认（无过滤、offset=0、limit=20），显式 query 仍须提供；类型、长度、枚举、数值边界与 schema 一致。闭合对象拒绝未知参数。可空数值过滤的空字符串也规范化为 null；真实基线/复跑发现的旧式 `None` 字符串在可空过滤、片段 assetId 和 timelineVersionId 上转换为 null，不能把它当作真实范围或版本 ID。
- 取消 Agent 的默认配音稿同意提问：要求先读素材证据再自动起草、直接执行。完成条件模型同时区分需原样保留的用户稿与待自动起草的稿；自拟稿的时长冲突可按实测 targetScriptLength 改稿、保持指定秒数重试，不问用户取舍。用户已提供/接受的原稿与明确秒数冲突仍保留必要取舍边界，完整的有引用策划与时钟由任务 6 接入。本任务不能宣称新策划链已完成。
- `confirmation.rs` 的最小额外接线：确认任务继承所确认源任务的 uiLocale；确认消息与配音失败提示按该语言生成。仅替换文案而不继承语言会一直回落中文，已有作用域/单次消费回归现包含英文继承断言。没有改 models/storyboard/phases/phase4/时间线/交付实现。
