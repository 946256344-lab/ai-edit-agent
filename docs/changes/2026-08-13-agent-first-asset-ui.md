# Agent-first 素材界面收敛

- 主工作区不再展示搜索、筛选、批量整理、集合和任务明细。
- 保留只读层级文件夹目录和派生证据信息：每级只显示直属子文件夹和直属素材，可逐级进入和返回；目录键只使用根名称与相对路径。单文件导入进入“未归类素材”，且不提供人工整理或剪辑操作。
- 兼容旧数据：若早期素材没有 `folder_reference`，但一批源路径存在共同父级，则只在内存中重建相对目录树；不迁移数据库，也不把绝对路径返回前端。
- 保留导入、整体分析汇总和源文件健康摘要。
- 只有检测到缺失、变化或不可读源文件时，才显示修复位置入口。
- 后端检索、分页、用户元数据、批量操作、健康扫描、片段检索和收集命令继续保留，供 Agent 或诊断调用。
- 同步文档：`docs/architecture.md`、`docs/decisions.md`、`TASKS.md`。
