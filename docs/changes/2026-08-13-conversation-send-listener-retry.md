# 对话发送事件监听恢复

## 变更

- 对话发送仍在调用 `submit_conversation_turn` 前确保 `agent-edit-completed` 监听已经建立，保留异步任务早到事件缓存和任务 ID 对账，不放宽完成事件安全边界。
- 监听在启动、窗口重新获得焦点及每三秒恢复周期中主动重试；成功后重复恢复调用为空操作。发送按钮不再因为首次注册失败而永久禁用，用户点击也会立即促成监听；注册成功后继续原请求，仍失败时保留输入并显示可重试提示。
- 项目或任务路由在尚未建立消息上下文前失败时不再静默返回，界面显示不含底层错误和用户数据的固定提示。
- schema v11 会修复早期已创建但缺少 `active_subgoal` 的 `task_state_snapshots` 表；这是现有本机数据库在 Task Resolver 刷新候选时失败的根因。
- 发送处理中继续禁用重复提交，并补充明确的禁用视觉状态。
