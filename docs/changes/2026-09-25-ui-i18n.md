# 2026-09-25：界面中英双语（第一步：前端文案）

## 结果

桌面应用界面可以在中文和英文之间切换。侧栏底部新增语言按钮，切换立即生效，偏好保存在本机；首次启动按系统语言选择（系统语言以 `zh` 开头用中文，其余用英文）。消息时间、会话更新时间和素材目录排序跟随当前语言。

## 范围

- `src/lib/i18n/`：`index.ts` 负责当前语言、切换、`useI18n()`、`messages()` 和随语言的时间/排序格式；`zh-CN.ts` 是词典基准；`en.ts` 以 `typeof zhCN` 声明，漏键即编译失败。
- `src/components/`、`src/hooks/`、`src/App.tsx`、`src/lib/asset-analysis.ts`、`src/lib/message.ts`：全部界面文案改为读取词典；`AppSidebar` 增加语言切换按钮，`WorkspaceIcon` 增加 `language` 图标。
- `AssetBrowser` 不再用标题文字判断是否为根目录，改为显式 `isRoot` 属性。
- `scripts/check-i18n-literals.mjs`：扫描 `src/` 下 `.ts/.tsx`，排除词典目录与注释，发现写死的中文即失败；已接入 `harness:check`、`harness:staged`，并提供 `npm run i18n:check`。
- `useArtifactWorkspaceController` 中两处用正则匹配 Rust 返回的中文原文，按规则以 `i18n-allow` 标注保留。

## 禁止变化

- 不改公开 Tauri 命令、前端 bridge、SQLite schema 或 Agent 工具目录。
- 中文界面的文案与改动前逐字一致。
- 界面语言不影响成片语言：配音、字幕、分镜文案仍跟随用户文案。

## 边界

- 新建项目、会话的默认名称和欢迎语按创建当时的界面语言写入数据库，之后切换语言不会改名。
- 已显示的一次性提示（如导入结果、交付失败原因）保持产生时的语言，下一次更新才换成新语言。
- 仍为中文或英文原样显示的内容：Rust 返回的状态与错误（OAuth/自定义 API 状态消息、发行检查项、模型下载消息、交付结果消息、镜头替换不可用原因）、编辑器名称（`linker.label`）、Agent 的回复。这些留给第二步。

## 验证

- `npx tsc -b`：通过。
- `npm run lint`：通过。
- `npm run harness:check`：通过，含新的界面文案检查。
- 浏览器中以临时页面模拟 Tauri IPC：工作台、模型设置、素材库、新建项目在中英文下均正常渲染，侧栏切换即时生效，`<html lang>` 与本机偏好同步更新；中文界面与改动前一致。
- 真实桌面（WebView2）切换与英文长文案布局待验收。
