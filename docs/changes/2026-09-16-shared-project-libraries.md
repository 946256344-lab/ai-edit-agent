# 新建项目与共享子素材库

## 结果

- 新建项目先填写项目名，再勾选全局子素材库，默认全部选中；支持单选切换、全选、取消全选和空库项目。取消 / Escape 不创建项目。
- 每个导入根文件夹对应子素材库，无目录素材进入“未归类素材”。项目关联库而非复制素材，复用原素材 ID 和分析结果；之后新建的其他库不会自动加入已有项目。
- Schema 18 增加库和项目关联，Schema 19 增加稳定成员关系，避免源目录重链路改变素材归属。旧项目仍可使用原素材。项目主动导入会加入对应共享库。
- 素材浏览、搜索、分镜候选、手动替换、字幕、预览音视频与剪映输出统一查询 project_asset_access；共享收藏、排除、健康和分析事实。
- 未添加用户未要求的画幅、时长、模板或其他配置。保留当前分支已有未提交改动。

## 验证

- npm build、lint、cargo fmt --check、cargo check 通过；lint / Rust 仅原有警告。
- Rust 库测试 352 项通过，排除原有 every_advertised_text_recipe_is_accepted_by_the_text_track_validator 字幕样式失败；契约集成测试 2 项通过。
- 新增共享关系回归覆盖旧项目范围、选定与未选库、空选择、不复制素材、重链路保留归属及重复迁移。
- 使用真实 ProjectCreationModal 与临时示例数据检查布局、默认全选、命名、取消部分、全选/取消全选和 Escape 关闭；临时页面已移除。该验证不代表真实桌面数据库创建成片已端到端验收。
- React 技能检查保持草稿状态在 controller，弹窗使用原生 dialog 和具名 checkbox；视觉检查修正旧 settings-dialog 样式覆盖。
- 同步修正上轮顶栏 props 数超过预算的问题，仅归并 actions，不改变窗口功能。
