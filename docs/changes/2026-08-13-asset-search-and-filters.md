# 素材搜索与组合筛选

## 变更

- 素材摘要新增独立的 `visualAnalysisStatus`，继续不向前端暴露绝对源路径，也不在列表查询中同步探测源文件。
- 素材库新增名称、文件夹和相对路径搜索。
- 新增媒体类型、技术分析状态、视觉分析状态、storyboard 可用性和顶层导入文件夹组合筛选。
- 显示筛选结果数量、无结果状态与一键清空入口。

## 边界

- 该变更不修改、移动或删除源媒体，不启动或重启桌面程序。
- “可用于 storyboard”仅匹配图片或视频中技术状态与视觉状态均为 `ready` 且已有视觉标签的素材。
- 当前筛选在前端对已加载素材执行；后端分页、查询下推和虚拟列表属于下一阶段。

## 验证

- `npm run lint`
- `npm run build`
- `cargo test --lib`
- `npm run harness:check`
