# 用户素材元数据与集合

- schema v12 新增独立的用户素材元数据、标签和集合表。
- 素材库支持批量收藏、评分、备注、禁止/恢复使用、标签和加入集合。
- 搜索命中本地备注和标签；分页支持收藏、禁止使用和集合过滤。
- 禁止使用素材从新 storyboard 候选中排除，历史产物不被改写。
- 用户正文不进入操作日志，集合不移动或修改源媒体。
- 未启动或重启桌面程序；迁移只会在以后运行新构建时执行。

验证：`npm run lint`、`npm run build`、`cargo fmt --check`、`cargo test --lib`、`npm run harness:check`。
