# 前端工作台体验优化

日期：2026-09-12。分支：`codex/frontend-polish`。

## 改动

- 统一浅色工作台的正文、按钮、状态、素材卡片及设置表单，侧栏增加文字标签。
- 对话输入框随文案增长；消息在底部时跟随更新，向上阅读时保留位置并提供「回到最新消息」。
- 素材改为自适应卡片网格，接通已有素材分析结果面板，缩略图延迟加载。
- 素材页参与正常布局，打开时隔离对话和预览的键盘交互。
- 预览展示真实时间线版本和镜头数量，候选区独立滚动。
- 设置使用原生模态对话框，支持 Escape 关闭和焦点返回。
- 800px 以下使用纵向工作台，390px 窗口仍保留素材库入口。

不增加依赖，不变更 Tauri 命令、数据库或剪辑流程。
