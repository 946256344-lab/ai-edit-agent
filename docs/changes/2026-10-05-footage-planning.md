# 素材盘点、体裁配方与有引用策划（任务 4）

分支 `feature/footage-planning`，新增内部模块和独立评测模式，不改产品决定、任务清单和已审定方案，不接 `generate_storyboard`。

## 行为与接口

- `inventory.rs` 完整分批理解片段，代码绑定逐片身份/完整源窗/证据引用与分析快照；模型回传自由可讲表达、原文锚点序号和缺口，代码回填原分析逐字引文。漏报 direct 不当直证，汇总仍保留低频片段，不建立场景/功能类目。因果关系须带原事实锚点，不能用相似设备或文件顺序推断。
- `genre.rs` 固定手选，自动单次判断与快照复用，信息不足默认宣传；自动叙事缺因果改花絮，手选叙事只交缺口。代码参数拥有段数、时长比例、默认时长和按最短可读镜长算出的镜数；用户秒数优先，源窗不足缩短。
- `planning.rs` 只消费调用方已过底线集合，核对引用身份/源窗、原分析引文、配方顺序/镜数、数字用户事实来源、重复主选源窗，宣传卖点禁气氛支持。每段主选/备选另由模型对原事实独立并发审核，最后审标题、必需画面和因果；非法或无直证提案拒绝，不给后续选镜硬凑。缺必需画面/完整叙事只交缺口，零合格片段失败，备选不足和短策划如实标受限。
- 返回任务 2 的 `StoryboardEvidenceMetadata`：`footage-first-v1`、`genre-recipe-2026-10-05-v1`、体裁、完整合格快照、主选和备选引用。任务 6 负责新版本事务落库；本轮不写历史项目/产物。
- 上游补核验或收窄合格窗须重新封印证据，盘点按同一 assetId/segmentId/analysisSnapshotId 绑定理解，策划重新使用当前合格 ID 和允许窗。每个基础片段最多一个合格窗；多离散窗需后续决定接口，不能修改源窗还沿用旧内容 ID。
- 每批 6 片段，遗漏/无效锚点只补读缺项一轮，仍不全失败。策划模型仅回传证据 ID 和锚点，代码回填完整合格窗及 supports，主动提供的错误身份/源窗仍拒绝。段审核与全局审核并发；严格 Schema 限定每段主选和备选审核数量及索引，仍由代码拒绝重复/缺项。不足最短可读时长的证据保留事实快照，但不进入模型提案候选。修复实测发现的 3D 技术名称被误判为产能数字；数值性能仍须用户事实。盘点只判断缺画面，不把配音/音乐开关、时长或底线裁决当成缺内容。
- 实测发现模型把时长/段序号写入可讲内容，触发数字来源门；将这些格式字段排除在提案内容约定之外，不放宽数值来源规则。无效策划逐次拒绝并在 `rejectedAttempts` 保留原因，最多反馈一次提出新的策划；新提案重新过全部引用、数字和语义门。不是传输重试，Provider 失败仍真实返回。
- 实测还发现汇总把钩子/音乐/收束当成缺画面并停工。全库汇总与独立需求覆盖审核并发；后者只判必需/可选人物、对象、动作、事件的缺口，不读汇总的结论，代码用它的必需画面缺项决定是否只能交缺口。叙事因果缺口仍单独保留。此审核仍是模型判断，不冒充人工金标。
- 提案和全库汇总逐片读取所有原语义字符串锚点，避免完整原事实与锚点重复发送；不按频次截断或删低频片段。逐片理解仍读完整时段/关系字段，独立审核仍读引用片段的原事实结构和时间，完整风险/关系结构仍在输入和返回事实快照。
- 每次请求附严格 JSON Schema：字段必需、数组元素形状明确、片段数与片段序号限定、策划证据 ID 限于合格输入。Custom/Gateway 使用 Chat 的嵌套 json_schema 格式，OAuth 使用 Responses 格式；都经统一 Provider，未更改 Provider 或模型，格式不支持时真实失败，不静默改走宽松格式。

## 最小接线与热点

`storyboard.rs` 仅新增三个 `pub(crate) mod` 注册；无主流程改动。`footage_eval.rs` 只注册独立评测子模块并在隔离环境断言后派发 `planning-only`。未改 models、phases、phase4、时间线、前端、Agent 或其他会话文件。

## 评测范围与验收边界

`run.py --planning-only --snapshot ... --workers 4` 跑工业基线 10 个 setup 请求加自动叙事缺因果/信息不足两例，各 3 次。仅盘点→体裁→配方→策划，真实 Provider，0 图/请求；独立请求并发，仅统一 Provider 的 429 退避。记录逐请求输入/响应、原证据、盘点、体裁快照、配方、计划、非法/越窗和空结果，绑定源码/二进制哈希。

上游合格集合可用 `--eligible-evidence` 传入；未提供时明确为语义隔离轨道，冻结库大量风险未知不能冒充安全或“合格工业用例通过”。合法引用不等于语义真实，模型审核不等于人工金标；缺口诚实、语义与体裁正确率金标缺失时保持 N/A。完整三体裁成片、桌面和发布验收属于后续任务。
