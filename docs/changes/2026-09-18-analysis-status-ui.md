# 素材分析提示收口

## 结果

- 导入弹窗仍是本批次分析的主界面：真实计数、预计剩余时间、后台分析和取消/继续。
- 侧栏「素材库」只在分析中或有失败/取消时显示状态点，不出现进度卡。
- 对话输入区平时不显示分析进度。用户发送后若素材未全部分析完，弹出确认：是否只用已分析素材开始剪辑。可取消、去素材库；有可用视频时才能确认。分析全部完成后自动开始。
- 素材库把四态筛选、进度条和取消/继续/重试收到列表标题。有素材时始终显示进度条。
- 去掉右下角 `AnalysisActivity` 浮层和输入区里的进度卡。标题上的「等待素材分析」不再与输入区重复。

## 边界

不改变分析状态口径、取消/继续命令或导入弹窗职责。失败重试仍在素材库执行。确认只属于当前打开的页面。用户确认只用已分析素材后，即使其余条目仍在分析也会开始剪辑；候选仍只收已分析 ready 的视频。

同步文档：`docs/architecture.md`、`docs/api.md`、`docs/codebase/STRUCTURE.md`、`TASKS.md`。

## 验证

- `npm run lint`
- 桌面开发版已在运行，需手动确认：导入弹窗仍弹出；侧栏状态点；素材库列表标题筛选与进度条；发送未分析完素材时出现确认弹窗；右下角不再浮层。
