# 素材分析进度与剪辑等待

## 结果

- 导入后自动打开本批次分析弹窗，按实际完成速度估算剩余时间；主按钮后台分析，次按钮取消。素材库、对话进度及浮层可取消项目分析，可继续已取消项；当前外部调用结束后退出，完成结果保留。
- 素材卡支持重命名、批量选择、全选当前列表和确认移除。移除隐藏共享素材索引，保留原文件和已有时间线引用；取消其未完成分析。

- 素材库顶部显示已分析、分析中、未分析、分析失败的分段进度与数量，点击状态筛选当前目录；项目级统计覆盖全库，不受分页影响。
- 导入期间持续显示状态，完成导入后自动转为分析进度；对话输入区同步展示。基础分析完成但画面识别未完成不再算已分析，画面失败不再误报无法读取。
- 用户可先写要求并提交等待；首次分析全部成功后只继续一次。失败保持等待，提供重试或明确选择仅使用已分析视频。全部失败不能继续。
- 取消等待保留文案；切换项目/会话取消旧等待。等待属于当前打开的页面，重启不自动恢复发送；没有提交请求不会自动剪辑。
- 提交时冻结文案和媒体选项。等待范围为当前项目选用的素材库；导入和重试入队期间不放行。Phase 4 镜头精修继续在剪辑阶段执行。
- 失败重试复用现有技术/视觉两阶段重试，按 200 项分批，先收集完整失败列表避免分页漏项。已排除、不可读或显式跳过的素材会保留原因，不静默重试。

## 边界

`list_asset_page` 新增 `analysisState` 筛选与 `progress` 返回值，旧 `counts` 保持原义；`readyVideo` 只统计可用于继续的已分析视频。视频/图片显式跳过识别属于未完成，四态汇总放在失败组，详情仍显示已跳过。候选读取新增首次视觉 ready 条件，失败素材的部分段卡不能进入剪辑。

无数据库迁移，无自动重试或 Provider 切换，无导出、物理删除或原始媒体修改。

同步文档：`docs/api.md`、`docs/architecture.md`、`docs/codebase/STRUCTURE.md`、`TASKS.md`。
