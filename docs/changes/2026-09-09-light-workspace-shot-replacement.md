# 浅色粗剪工作台与手动换镜

产品收敛为「素材 → 对话粗剪 → 预览/换镜 → 剪映草稿」。B 浅色工作台固定左侧对话、右侧预览；项目和会话收进窄侧栏菜单，素材管理按需打开，主操作为「生成剪映草稿」。完整 Studio、最终视频导出、总素材库和 Agent 整轮撤销不在本次范围。

右侧定位镜头后可打开最多 12 个真实推荐候选，试选只准备该候选的静音画面；保存才产生新版本，保留槽位时长及其他镜头、字幕、配音和音乐。提供手动替换的撤销/重做。未保存时发送对话或切换上下文，可保存并继续、放弃并继续、继续编辑。旧预览保留到新预览成功，保存失败与预览失败分别提示。

Rust 在生成 storyboard 的事务中持久化原 Top-12。老版本可主动用现有分析证据生成推荐；试选复用当前切点精修和构图，保存复用 Studio 提交并原子写入版本与操作记录。前端由新 controller 管理暂存候选和异步结果作用域。公开接口见 `docs/api.md`，代码定位见 `docs/codebase/STRUCTURE.md`。

开发期间远端更新至 `1c05d2f`（片段级理解），已合入并适配：候选通过 `candidateId` 区分同素材的不同片段，卡片展示源时间范围与片段缩略图；本地持久化显式保留 segment，选定片段的精修范围不能越界。旧素材按已有真实分段展开，不触发重新识别。Schema 顺延至 17，与远端新增的片段证据表兼容。
