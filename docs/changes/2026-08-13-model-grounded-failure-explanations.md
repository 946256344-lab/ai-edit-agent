# 模型基于脱敏事实解释工具失败

- Agent loop 不再只向下一轮模型回读单一安全错误码，而是提供临时结构化诊断：操作、失败阶段、安全码、计数事实、可重试性、恢复建议和表达约束。
- 诊断不包含完整本机路径、原始日志、媒体证据、用户内容或底层错误原文，也不写入 payload-free 步骤/诊断表。
- storyboard 在视觉证据候选存在但源文件均不可访问时，提供候选数和可访问数，使模型能准确说明需要重新连接或重定位素材。
- 没有任何视觉证据候选时使用独立诊断，建议先完成或重试视觉分析，不误报为源文件失联。
- 模型可在无产物失败后通过 `finish.answer` 自然说明原因；后端仍将任务保持为 `failed`，并添加“任务未完成”事实前缀。明显的完成/成功声明会被拒绝；模型不可用时保留固定降级回复。
