# 素材批量操作与任务中心

## 变更

- 窗口化素材行增加独立复选框，最多选择 200 条，支持选择当前已加载结果和取消选择。
- 新增受控批量技术分析重试；已 ready 或已有活动任务的素材不会重复排队。
- 新增需确认的批量视觉分析跳过；仅作用于当前项目技术 ready 的图片/视频，保留技术证据并清除视觉标签。
- 新增素材任务中心，分别显示技术与视觉的运行、排队、失败和跳过，并列出最多 50 条安全失败记录。
- 批量操作写入 `operation_logs`，actor 为 `user`；日志只保存数量，不保存路径或媒体内容。

## 竞态与边界

- 单批上限为 200，跨项目素材令整个操作失败。
- 用户显式跳过写入固定原因码；已经在途的视觉批次完成后不得覆盖该状态。
- 技术分析重试仍在实际使用前验证源文件；缺失源媒体不会被伪装成已排队。
- 不删除、移动或改写源媒体，不启动或重启桌面程序。

## 验证

- Rust 定向测试覆盖用户显式跳过优先于在途视觉完成。
- `npm run lint`
- `npm run build`
- `cargo fmt --check`
- `cargo test --lib`
- `npm run harness:check`
